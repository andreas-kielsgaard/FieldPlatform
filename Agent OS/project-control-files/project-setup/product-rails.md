# Product Rails

## Identity

Field Platform is a field-orientation and participation platform.

It is not a feed, chat app, generic social network, event directory, community operating system, or recommendation engine.

## MVP Proof

The MVP proves:

- orientation
- entry
- light continuity
- stewarded representation
- reviewable nudges and relation claims
- controlled visibility, publishing, and review basics

The first slice should prefer a public community orientation page over generic events CRUD.

Use `../field-platform-product-rails.md` for the fuller product guardrails.
