# Task-Size Context Loading

## Status

Deferred.

## Note

The proposed operating system introduces a lot of context: root instructions, source maps, task-mode instructions, control-surface maps, structural indexes, ledgers, and review checklists.

Later migration work should decide how much of this scaffold an agent should consume based on task size and risk. Small read-only tasks, narrow edits, substantial cross-surface changes, and review-before-commit work may need different orientation depth so the operating system remains useful without becoming procedural drag.
