# Generated Design Instructions Archive

This folder contains older generated research, design briefs, business-case material, soft context, and revision instructions.

It is preserved for reference only. It is not current product-design authority.

Use this archive only as reference or inspiration. If an idea is adopted, distill it into `General context/`.

Authority order:

1. Current explicit user instruction.
2. Current `General context/` docs.
3. Recent mockup review findings captured in General context.
4. Platform data layer docs for implementation interface truth.
5. Current mockup README for that mockup's intent.
6. This archive as optional reference only.

Some content here may over-emphasize map, rhythm, or home directions compared with the current object-page and connection work. Some business assumptions are unvalidated. Some UI prescriptions and implementation instructions predate the current Platform data layer and FieldRelation/object-surface guidance.

Code/execution agents should not consult this folder unless explicitly instructed or the prompt is about reorganizing/reference material.
